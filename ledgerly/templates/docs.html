API reference

The public surface of this deployment. Base URL: {{ api }}

Authentication

Sessions authenticate via the {{ ctx.tech.cookie }} cookie. API calls can also send Authorization: Bearer lk_live_....

Endpoints

MethodPathDescription
GET {{ api }}/clients List your clients.
GET {{ api }}/clients?filter=<json> Filter clients with a JSON query document.
GET {{ api }}/invoices/<id> Fetch a single invoice by id.
PUT {{ api }}/team/me Update your own profile fields.
GET {{ api }}/keys List the API keys currently accepted.
GET {{ api }}/v1/health Deployment health status (unauthenticated).
POST /auth/partner?code=<code> Complete a partner (OAuth) sign-in flow.
GET /graphql GraphQL gateway for workspace queries.
GET /documents/<path> Open a stored document by path.
GET /invoices/<id>/status Status card for an invoice.
GET /billing/return?next=<url> Return from an external billing flow.
POST /reports/export Export a report to a named format.
POST /coupons/redeem Redeem a promo code against the balance.

Reporting desk

The reporting desk (reports, flags, analytics, triage) runs on a separate port for this deployment: {{ meta_base }}. It shares your session cookie, so no re-login is needed.

Example

curl {{ request.url_root }}clients

Replace {{ request.url_root }} with your tunnel or host if you are testing remotely.
